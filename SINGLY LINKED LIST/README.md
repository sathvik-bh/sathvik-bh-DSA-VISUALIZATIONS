# 🔗 Singly Linked List Visualizer

An interactive **Singly Linked List Visualizer** designed to demonstrate how nodes are connected and manipulated in a linked list.

Built using HTML5, CSS3, and Vanilla JavaScript, this project provides a visual learning environment for understanding linked list operations through interactive demonstrations.

Users can perform insertion, deletion, searching, traversal, and reversal while exploring how nodes and pointers work internally.

---

## 📖 About Singly Linked Lists

A Singly Linked List is a linear data structure consisting of nodes.

Each node contains two components:

1. **Data:** Stores the actual value.
2. **Next Pointer:** Stores a reference to the next node in the list.

The last node points to `NULL`, indicating the end of the linked list.

Unlike arrays, linked list elements are not required to occupy contiguous memory locations.

---

## ✨ Features

- **Interactive Node Visualization:** Displays nodes and their connections.
- **Insertion Operations:** Insert nodes at different positions.
- **Deletion Operations:** Remove nodes using different approaches.
- **Search Functionality:** Search for a particular value.
- **Traversal:** Visit and display nodes sequentially.
- **Reverse Operation:** Reverse the order of nodes.
- **Clear List:** Remove all nodes from the linked list.
- **Pointer Visualization:** Understand how nodes are connected through next pointers.
- **Beginner-Friendly Interface:** Makes linked list concepts easier to understand.

---

## 📋 Supported Operations

| Operation | Description | Time Complexity |
|---|---|---|
| Insert at Beginning | Adds a new node at the start of the list. | O(1) |
| Insert at End | Adds a new node at the end of the list. | O(n)* |
| Insert at Position | Inserts a node at a specified position. | O(n) |
| Delete at Beginning | Removes the first node. | O(1) |
| Delete at End | Removes the last node. | O(n) |
| Delete at Position | Removes a node from a specified position. | O(n) |
| Delete by Value | Searches for and removes a node containing a specified value. | O(n) |
| Search | Finds a node containing a particular value. | O(n) |
| Traverse | Visits every node sequentially. | O(n) |
| Reverse | Reverses the linked list by changing pointer connections. | O(n) |
| Clear | Removes all nodes from the linked list. | O(n) |

*Complex
